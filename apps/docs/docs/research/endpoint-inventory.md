# Endpoint inventory and coverage matrix

Verified 2026-09-24 by SEC documentation and the recorded responses below. Requests use ten-digit CIKs for `data.sec.gov`. Archive directory CIKs omit leading zeros.

| Public source                                                 | Shape and update behavior                                                                     | Client status                                                                                    | Fixture and limitation                                                       |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| `/files/company_tickers_exchange.json`                        | `fields` plus `data` row arrays; periodically updated                                         | Implemented                                                                                      | `apple-ticker-lookup.json`; SEC does not guarantee mapping scope or accuracy |
| `/files/company_tickers.json`                                 | numbered objects with ticker, name, CIK                                                       | Raw only                                                                                         | not independently captured in fixture; regular lookup uses exchange file     |
| `/files/company_tickers_mf.json`                              | fund series/class mapping                                                                     | Raw only                                                                                         | funds not normalized                                                         |
| `/submissions/CIK##########.json`                             | metadata, column-oriented `filings.recent`, referenced history files; usually updated rapidly | Implemented                                                                                      | `apple-submissions-fy2025.json`; fixture is reduced                          |
| Referenced `/submissions/CIK...-submissions-NNN.json`         | older column arrays                                                                           | Implemented, all references followed in `filings.list`                                           | `apple-older-submissions-sample.json` is first three rows                    |
| `/api/xbrl/companyfacts/CIK##########.json`                   | standard taxonomy entity-wide facts by concept and unit; normally under-minute update         | Implemented                                                                                      | `apple-companyfacts-fy2025.json`; custom/dimensional facts absent            |
| `/api/xbrl/companyconcept/CIK.../{taxonomy}/{tag}.json`       | one concept by unit                                                                           | Implemented                                                                                      | `apple-net-income-concept.json`                                              |
| `/api/xbrl/frames/{taxonomy}/{tag}/{unit}/{frame}.json`       | one latest fact per company near calendar period                                              | Implemented as raw frame; never used for company fiscal selection                                | `apple-assets-frame.json`                                                    |
| `/Archives/edgar/data/{CIK}/{accession-no-dashes}/index.json` | archive document list                                                                         | Implemented                                                                                      | `apple-q2-archive-index.json`; files may later be removed                    |
| Archive XML/Inline XBRL documents                             | filing-level custom and dimensional facts                                                     | Document retrieval and `_htm.xml` numeric extraction implemented; Inline HTML extraction pending | `apple-custom-xbrl-sample.xml`; canonical custom mapping remains unsupported |
| Daily/full/quarterly indexes                                  | filing catalogs, update/rebuild timing differs                                                | Unsupported                                                                                      | no fixture                                                                   |
| Bulk ZIP archives                                             | nightly snapshots                                                                             | Unsupported                                                                                      | ordinary company requests avoid them                                         |
| Financial statement data set ZIPs                             | as-filed rendered-face numeric rows                                                           | Unsupported                                                                                      | distinct from companyfacts; not a substitute for filing                      |
| Full-text search                                              | separate search product, not guaranteed public data API                                       | Unsupported                                                                                      | no undocumented search endpoint used                                         |

SEC source: [public data APIs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces), [archive and lookup files](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data).
