# Release report — 0.1.0 preview

**Date:** 2026-09-25. This is an unofficial, read-only local client. The package and site were not published. `@sec-edgar/research-client` is a provisional npm name; registry checks found that path absent, but an owned scope is required before publication.

## Verification

On fnm-managed Node 24.21.0, `npm run check` passed on 2026-09-25. It ran formatting, lint, package/example type checks, ESM build, 80 deterministic package tests, two separate live-contract unit tests, core coverage gates, the production dependency audit, a clean `npm pack` import, 14 executable documentation snippets, and a Docusaurus production build with no broken links. The packed consumer printed `packed ESM import: ok`. The 18-request mocked load stayed below nine starts per rolling second and under ten seconds; the generated 100-entry local bulk import took under two seconds. Core coverage gates remained green, including selector 100% lines/90.30% branches, currency 100%/92.31%, validation 100%/95.65%, Inline XBRL 93.55%/87.69%, and snapshot 98.37%/80.49%.

`npm audit --omit=dev --workspace packages/sec-edgar` reported zero production-library vulnerabilities. A separate full workspace audit still reports 22 development-tooling findings (21 moderate, one high) in the Docusaurus/Webpack chain, including `serialize-javascript` and `uuid`, with no npm fix available at the audit date. The docs toolchain is not a zero-finding build. No live SEC contract run was claimed: `SEC_USER_AGENT` is absent locally, and the weekly workflow needs a genuine contact secret. The package and site were not published.

## Server operation and bulk completion

[PR-06](backlog/production-readiness.md) adds an optional shared file limiter and pluggable `SharedRateLimiter`, a bounded and abortable queue, abortable retry waits, configurable circuit, and transport metrics. Two real Node child processes share a rate budget in a deterministic test. A mocked 18-request load exposed and then verified a correction to rolling-window process spacing. Cross-host deployments must supply a common coordinator; see [ADR 018](decisions/018-shared-traffic.md) and [server operations](guide/server-operations.md).

[PR-07](backlog/production-readiness.md) adds byte-bounded memory and persistent file caches, expiry/provenance metadata, atomic replacement, explicit refresh, HTTP 404 invalidation, and a separate bounded local ZIP importer with optional CIK filtering. A 100-entry generated ZIP containing recorded SEC submissions shapes met the declared two-second local budget. [SEC HEAD/range observations](research/research-log.md#2026-09-25-pr-0608-server-operation-and-nightly-bulk) measured 1,409,389,023 compressed bytes/20,396 entries for company facts and 1,565,294,470 bytes/991,556 entries for submissions on 2026-09-25 UTC; the full archives were not downloaded. See [ADR 019](decisions/019-persistent-cache-bulk.md) and [cache and bulk](guide/cache-and-bulk.md).

[PR-08](backlog/production-readiness.md) now has a fixture-backed [compatibility matrix](guide/compatibility-matrix.md), health alerts, a one-request-per-second weekly live contract workflow, load/failure-injection tests, and release gates for packed import, dependency review, and docs. **The live activation gate remains open** until a real `SEC_USER_AGENT` secret is configured and the first scheduled run passes. See [ADR 020](decisions/020-operational-monitoring.md) and [monitoring](guide/monitoring.md).

## Precise unsupported coverage

Normalized statements do not automatically incorporate custom or dimensional XBRL facts. `filings.xbrlFacts` exposes supported `_htm.xml` and Inline HTML numeric facts for inspection; continuations, nested numeric facts, additional transform registries, multi-document Inline sets, and older non-XBRL formats remain unsupported. The tested bank, insurer, REIT, investment-company, and IFRS mappings do not establish universal industry coverage. Fund series/class lookup is raw only. Local company-facts/submissions ZIP import is implemented with bounds and CIK filtering, but a full official ZIP import has not been verified; large all-company storage requires a purpose-sized sink. Historical daily/full indexes and full-text search remain unsupported. Authenticated EDGAR Next submission and account management are outside the product. Cross-host organizations need a shared limiter adapter, and the scheduled live workflow requires a contact secret. See the [coverage matrix](research/endpoint-inventory.md), [limitations](guide/limitations.md), and [backlog](backlog/production-readiness.md).
