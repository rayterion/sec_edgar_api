# Release report — 0.1.0 preview

**Date:** 2026-09-24. This is an unofficial, read-only local client. The package and site were not published. `@sec-edgar/research-client` is a provisional npm name; registry checks found that path absent, but an owned scope is required before publication.

## Verification

Run `npm run check` from the workspace root on Node 24.21.0. It runs Prettier, ESLint, strict package and example type checks, ESM build, deterministic tests, per-module coverage gates, production dependency audit, `npm pack` installation into a clean consumer, eight executable docs snippets, and a Docusaurus production build. The final run passed. The deterministic suite has 26 passing tests. Core coverage targets passed: selector 97.87% lines / 90.41% branches; fiscal periods 83.64% / 80.49%; JSON parser 100% / 86.96%; XBRL parser 82.11% / 73.17%. The packed consumer printed `packed ESM import: ok`; docs built with no broken links.

`npm audit --omit=dev --workspace packages/sec-edgar` reported zero production-library vulnerabilities. The full workspace audit still reports one high-severity `serialize-javascript` finding in Docusaurus build tooling with no npm fix available, plus moderate tooling findings. Do not treat the site toolchain as a zero-finding build. The separate live smoke suite requires a genuine `SEC_USER_AGENT` contact and was not run as a gate; direct declared-agent SEC requests were used to collect the fixtures.

## Precise unsupported coverage

Canonical statements do not automatically incorporate custom or dimensional XBRL facts; `filings.xbrlFacts` exposes them from supported `_htm.xml` instances for separate inspection. Inline HTML-only instances, unverified XML transformation variants, and older non-XBRL filing formats are not semantically parsed. Industry-specific and broader IFRS mappings remain partial. Fund series/class lookup is raw only. Bulk ZIP ingestion, historical daily/full indexes, and full-text search are separate unsupported capabilities. Authenticated EDGAR Next submission and account management are outside the product. See the [coverage matrix](research/endpoint-inventory.md) and [prioritized backlog](guide/limitations.md).
